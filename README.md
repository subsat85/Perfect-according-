# PERFECT — النظام المحاسبي

تطبيق محاسبة لمعرض PERFECT في إربد. فيه:

- المبيعات والمشتريات والتجار
- المخزون حسب الطابق والمستودع، مع النقل والجرد
- المصاريف والفواتير
- الرواتب والسلف
- تقارير الأرباح، والتصدير لـ Excel

## التشغيل
الموقع بيشتغل على GitHub Pages. من **Settings ← Pages** اختار Branch `main` والمجلد `/ (root)`.

على الموبايل، افتح الرابط من Safari واختار **مشاركة ← إضافة إلى الشاشة الرئيسية**. هيك بيشتغل كتطبيق، والمتصفح ما بيمسح بياناته.

## البيانات
- هاد المستودع فيه **الكود بس**، وولا رقم مالي بينحفظ فيه.
- البيانات بتنحفظ على الجهاز اللي بتستعمله (IndexedDB بالمتصفح).
- **نسخة احتياطية:** من الإعدادات بتنزّل ملف JSON، وبتقدر ترجعه على أي جهاز. النسخة الاحتياطية اللي بتنزّلها من نسخة Claude بترجع هون كمان.
- **مزامنة (اختيارية):** بتحفظ نسخة بمستودع GitHub **خاص** منفصل، مثلاً `perfect-data`، باستعمال توكن Fine-grained.
